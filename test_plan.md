# Test Plan - Seed of Thought (생각의 씨앗)

This plan outlines the testing strategy for the MVP of 'Seed of Thought'.

## 1. Core Scenarios to Test (The Happy Path)
1. **Scenario 1: Book Search**
   - Search for a book (e.g., "어린왕자").
   - Select a book and navigate to the sentence input screen.
2. **Scenario 2: Sentence Input & OCR**
   - Enter a sentence manually.
   - (Mock) Use OCR to fetch a sentence from an image.
   - Submit and trigger AI chat room creation.
3. **Scenario 3: AI Conversation**
   - Start a chat with the AI "Sprout Assistant".
   - Send messages and receive empathetic, child-friendly AI responses.
   - Maintain conversation history.
4. **Scenario 4: Diary Generation**
   - Trigger the "Make Diary" button after sufficient conversation.
   - Verify AI generates a 3-5 sentence draft diary.
   - Edit and save the diary.
5. **Scenario 5: Archive & Report**
   - View saved diaries in the Archive.
   - View the Growth Report with keywords and emotion statistics.

## 2. Backend Testing Strategy
- **Unit Tests**: Test `ChatService` (persona logic), `DiariesService` (summary logic), and `BooksService` (API mapping).
- **API Tests**: Use a script to verify endpoints:
  - `GET /books/search?q=...`
  - `POST /seeds`
  - `POST /chat/start`
  - `POST /chat/:id/message`
  - `GET /diaries/draft/:id`
  - `GET /diaries/report?userId=...`

## 3. Frontend Testing Strategy
- **Static Analysis**: Run TypeScript type checks (`tsc`) and Linting.
- **Navigation Check**: Verify all `navigation.navigate` calls use valid screen names.
- **Prop Logic**: Verify that data passed between screens (book, seed, chatRoomId) is handled correctly.

## 4. Execution Steps
### Step 1: Backend Static Check & Unit Tests
- Run `npm run test` in the backend folder.
- Fix any broken initial test files generated by NestJS CLI.

### Step 2: Backend API Verification (Manual/Script)
- Ensure the database is running (Prisma).
- Verify endpoints with sample data.

### Step 3: Frontend Static Check
- Run TypeScript compiler in the frontend folder to check for errors.
