# Seed of Thought (생각의 씨앗) 🍎🌱

AI-powered diary service for children.

## 🚀 Getting Started

### Backend
1. `cd backend`
2. `npm install`
3. `cp .env.example .env`
4. `npm run start:dev`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npx react-native run-ios` # or run-android

## 🛠 Tech Stack
- **Frontend**: React Native, Zustand, Styled-components
- **Backend**: NestJS, Prisma, PostgreSQL
- **AI**: GPT-4o-mini, Whisper, Google Vision OCR
